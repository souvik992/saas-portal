# posinext.com website

Plain static HTML in `public/`, generated by `src/build.py`. The pages ship no JavaScript, and each page carries its CSS
inline (one request to render). They are built to load on slow 2G connections: about 7–12 KB gzipped per page, WebP images
sized for the screen (`srcset`) and lazy-loaded below the fold, and self-hosted fonts with `font-display: optional`, so
text never waits for a font.

The design is the original Lovable site's (gallery-of-stories.lovable.app), rebuilt by hand in `src/site.css`.

## Change the site

Edit the sources, then run the build (Python 3 with Pillow):

```bash
python site/src/build.py
```

| File | What it holds |
|---|---|
| `src/kit.py` | Reusable parts: page shell (head, SEO meta, JSON-LD), header, footer, buttons, cards, FAQ, CTA band, breadcrumbs, icons, images |
| `src/products.py` | The 9 products: home-page blocks and each product page (features, steps, FAQ) |
| `src/build.py` | Home page, product pages, image conversion |
| `src/pages.py` | Features, pricing, changelog, compare, about, careers, contact, book a demo, docs, help, status, privacy, terms, security; 404, sitemap, robots, llms.txt, llms-full.txt, ard.json |
| `src/posts.py` | Blog posts |
| `src/site.css` | All styles (minified and inlined by the build) |
| `src/images/` | Original images; the build makes `public/img/<name>-480/800/1200.webp` |

Add a page: call `simple(...)` in `src/pages.py` (or add a product to `products.py`), and add it to `FOOTER` in `kit.py`
if it belongs there. The sitemap and llms files are regenerated from what was built.

## Put it on the server

On the PosiNext Cloud server (it runs Caddy), after DNS for `posinext.com` and `www.posinext.com` points at it:

```bash
curl -fsSL https://raw.githubusercontent.com/souvik992/saas-portal/main/site/deploy.sh | sudo bash
```

Run it again after changing the site (commit the built `public/` first). `www.posinext.com` redirects to `posinext.com`.
Unknown addresses return a real 404 with `404.html`. The script only writes `/etc/caddy/posinext-site.caddy` and undoes
everything if Caddy does not accept the result.

## Notes

- **Sign in** opens `https://portal.posinext.com/login`; **Start your free trial** opens `https://portal.posinext.com/register`.
- **Book a Demo** (`/book-a-demo/`) has no script: its form opens WhatsApp with the visitor's details filled in, or an
  email to `support@posinext.com`. The only email address shown anywhere is `support@posinext.com`.
- Prices on `/pricing/` match the portal's plans (`cloud/saas-web/src/plans.ts`); change both together.
- After a deploy, submit `https://posinext.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
