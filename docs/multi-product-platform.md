# Products

| Product code | Product | Windows app | Add-ons |
|---|---|---|---|
| `fine_dine` | Fine Dine | DinePOS | Table QR |
| `tiffin_qsr` | QSR | Tiffin POS | ODS (online orders) |

A customer account can use one or both products. Each product has its own 30-day trial: the app asks for the portal
email and password on first start and gets a licence key for that PC from DinePOS Cloud.

The product, account, licence and download rules live in DinePOS Cloud (fine-dine `cloud/hub`; ADR-0007). This
repository only shows them.
